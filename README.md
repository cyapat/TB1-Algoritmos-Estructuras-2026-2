# TB1 Algoritmos y Estructuras de Datos 2026-2 - Pinterest

Proyecto grupal para el Trabajo 1 del curso Algoritmos y Estructuras de Datos.

## Caso asignado

Grupo 9: Recomendacion visual Pinterest.

Estructuras sugeridas por el enunciado:

- Lista simple para tableros.
- Lista doble para categorias.
- Cola para recomendaciones.
- MergeSort para ordenar por popularidad.
- Recursividad para calcular o buscar similitud entre pines.
- Archivos para cargar y guardar colecciones.

## Requisitos clave del trabajo

- Programacion Orientada a Objetos y programacion generica.
- Cada integrante trabaja minimo 5 entidades con relaciones y aporte al UML.
- Minimo 3 estructuras de datos distintas en el proyecto.
- Cada estructura debe usar templates.
- Cada integrante debe aplicar al menos 3 lambdas.
- Cada integrante debe implementar 1 algoritmo de ordenamiento avanzado.
- Cada integrante debe incluir al menos 1 metodo recursivo.
- Consola usable y clara.
- Uso de archivos de texto o binarios para leer y guardar registros.
- Declarar uso de IA en la bitacora del informe.

## Como compilar rapido

Con g++:

```bash
g++ -std=c++17 TB1-Pinterest.cpp -o TB1-Pinterest
./TB1-Pinterest
```

En Visual Studio 2022, abrir el proyecto/carpeta y ejecutar `TB1-Pinterest.cpp`.

## Flujo sugerido para el equipo

1. Cada integrante trabaja en su propia rama.
2. Antes de subir cambios, compilar y probar el menu principal.
3. Mantener entidades separadas por responsabilidad para evitar conflictos.
4. Documentar en el informe que hizo cada integrante.
